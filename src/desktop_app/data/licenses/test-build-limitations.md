# 測試版限制說明

本安裝包是測試版，以下限制依使用者 2026-11-18 的 A13-6 決定列出。

- 測試版非正式版。
- ONNX 繁體中文準確度有已知缺口（內建 Tesseract 不受影響）。
- RAM 為軟性預算。
- 未在乾淨 Windows 10／11 實機完整驗收。
- GPU 未在實卡驗證。
- 部分內含元件版本未知，已列於隨包的 `licenses/known-gaps.json`（人讀版本為 `licenses/known-gaps.md`）。
- 安裝程式與 tesseract.exe 無程式碼簽章。
- 問題請回報到 GitHub Issues：https://github.com/ChouTa-chuan/MarkItDown-exe/issues
