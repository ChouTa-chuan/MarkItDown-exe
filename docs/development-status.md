# 開發進度

更新：2026-11-04。視覺版見 [里程碑與模組儀表板](progress.html)，資料來源 progress.json。

## 本輪完成

- PDF 精準模式逐頁自動判斷原生文字、掃描／混合內容、解碼異常與空白頁。
- CPU OCR（Tesseract）、繁體中文／英文固定模型、灰階與字高正規化、最多兩輪及逾時限制。
- 原生有框線表格去重、簡單雙欄閱讀順序、來源頁碼、路由與品質提醒。
- 桌面及 CLI 可選快速／精準，完成摘要顯示頁數、OCR 頁與提醒數。
- 官方 OCR 模型下載腳本，固定提交及 SHA-256 驗證；原生 OCR 執行檔尚未打包。
- Linux／Windows Python 3.12 雜湊鎖定檔、上游來源驗證、Windows 建置腳本及僅手動觸發 CI。
- PyInstaller 當前平台建置與真實打包程式的文字／PDF 功能檢查。

## 驗證

- 不繼承系統套件的乾淨 Linux venv，依雜湊安裝並以本機來源建置；44 項測試通過，無跳過。
- 包含繁中／英文掃描、混合 PDF、表格不重複、雙欄順序、空白頁與解碼判斷、取消、缺引擎錯誤與最多兩次 OCR。
- 掃描案例與原始 MarkItDown 比較，精準流程增加該案例的辨識內容；非整體準確率結論。
- Linux 資料夾執行檔實際完成中文文字與 PDF 轉換；非只檢查程序啟動。
- Windows workflow／spec 通過靜態檢查，但 Windows 安裝與建置未執行。
- 互動進度頁的里程碑、模組、篩選、鍵盤與手機版面檢查通過。
