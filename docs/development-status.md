## 驗證證據

- Linux／Python 3.12 虛擬環境：31 項測試全部通過，無跳過。
- 五種格式整合測試：DOCX 標題／表格、XLSX 工作表／數值、PPTX 標題／內容、HTML 結構、文字型 PDF；不是複雜版面或掃描準確率評測。
- 三項 Qt 離屏測試：設定儲存、缺少輸入提示、視窗控制 → 背景轉換 → 預覽。
- Chromium：檢核計數、模組、篩選、鍵盤切換、手機寬度及 JavaScript 錯誤檢查通過。
- 先前 1,300,000 bytes 中文純文字 CLI 已逐位元組比對一致。
- Windows、GPU 與安裝包尚未驗證。

- 資源估算未經 Windows／模型負載校準；RAM 是軟性預算。
- Office／PDF 原生函式期間不能即時協作暫停，後續需拆逐頁流程。
- 未完成 Windows 硬限制、CPU 內部執行緒、磁碟配額、持久化佇列及崩潰清理；強制終止可能留暫存。
- 目前虛擬環境使用系統套件作基礎；乾淨環境及依賴鎖定仍待驗證，不宣稱完整安裝可重現。
- 進度 HTML 是本地快照，並非應用程式介面。
- 後續先完成 Windows 建置與依賴重現，再進入自動精準及 GPU；修改上游時附回歸樣本。
