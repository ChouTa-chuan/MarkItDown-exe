## 舊版與新版的差異

| 範圍 | 舊架構核心 | 新架構 v0.4 |
| --- | --- | --- |
| 桌面／任務／分析／資源／品質 | 原有處理流程 | 沿用並接入元件能力解析 |
| 安裝與初始設定 | 已有開發安裝來源，OCR 仍需指定引擎／模型 | 基本包目標內含執行環境與雙語 CPU OCR，新增首次啟動精靈 |
| 元件管理 | 固定 Tesseract 模型管理 | 通用版本、依賴、下載、驗證、修復、移除與回復 |
| 選配引擎 | ONNX 與主開發包綁定；CUDA 是候選實作 | 獨立選配 CPU／GPU 工作程序，隔離 runtime |

前四份圖保存當時 0/12 的規劃；C01／C02／C05／C06／C07／C08 圖各保存當時實作狀態。C09 新圖另保存流程子檢核；現況為既有 19/25、新導入 7/12，C10 接線完成；C03 四語、來源及 Linux 內含整包已驗（3/4），Windows 實機未驗；C04 依賴與 Linux 核心打包／自檢兩項子檢核已驗，完整 C04／C09 仍待基本包，Windows／GPU 與已知 OCR 品質限制保留。

第二十份：[Windows 原生建置與四語部分實測](versions/v0.4-windows-native-ci.md)，保存 CI #3 已通過範圍與中文搬移失敗／UTF-8 待驗，不倒填舊圖。

## 保存規則

- 已存圖檔保留固定內容；下次架構變更新增另一份版本快照，再補索引與 CHANGELOG。
- 原始圖、對話原圖與回溯整理圖需註明來源，不把事後整理誤列為歷史原圖。
- [snapshots.json](snapshots.json) 保存各檔與 Mermaid 的 SHA-256；固定 Git 提交連結可追溯當時首頁／指引。
- 各份圖按當時狀態保存，不把新進度倒填舊圖；程式更新不等於已發布安裝包。
