# 原生文字型 PDF 無框線表格

精準模式新增保守的文字對齊推測，不使用此路徑辨識掃描表格，也不代表已有完整深度版面模型。

## 可接受的基線

- 至少三列（文字型首列與兩列資料），兩至八欄。
- 各欄左緣或右緣穩定，列距規則且互不重疊。
- 至少一個資料欄大部分是可辨識數值；僅含文章敘述、首列全為數字或欄位漂移者不強制轉表格。
- 以 Markdown 輸出，標記 inferred-borderless-table，提醒首列與欄列屬推測，需核對。

推測器也可處理已有框線表格後的剩餘文字，同頁兩種類型不互相吞掉。只排除已輸出的字元，保留前後正文，特殊字元跳脫。

## 資源與限制

超過 20,000 詞時跳過後續表格／雙欄對齊推測，保留原生文字。這是分析階段上限，不是整個 PDF 解析器的 RAM 硬上限。正常路徑重用同一份詞座標，避免重複提取。分析包含取消 checkpoint。

全為文字的表格、缺格、錯落列、複雜換行、旋轉、跨頁、掃描表格及不明確表頭尚未完整支援。對齊不等於表格；不明確案例不強制建立欄位。純數值首列也不擅自當作標題。

## 上游補驗與已知缺口

補驗 Microsoft MarkItDown 固定提交的 SPARSE-2024-INV-1234_borderless_table.pdf，來源與 SHA-256 位於 tests/fixtures/UPSTREAM.json，原 MIT 授權保留。

此上游測試報表包含缺格與錯落列。其單欄外框內其實有多欄文字；已修正不再壓成錯誤的單欄表格，而是保留文字與警告。首表仍未還原成正確六欄，嚴格結構測試保留為 expectedFailure；第二頁已可保留既有欄列。

這是上游公共測試資料，不是實際使用者文件。不能將「文字仍在」當作「表格結構已正確」。原 ONNX 繁體品質缺口也仍存在，兩項未達標均在進度頁揭露。

## 證據

測試涵蓋兩欄／三欄數值、右對齊數字、有框線與無框線同頁、前後正文、雙欄文章、數字首列、漂移欄位、上限與取消，以及上游樣本內容保留與未達標結構。仍需真實來源文件及更完整版面模型驗收。
