# 決策 0006：內含 OCR 使用明確資產契約與唯讀自動路徑

日期：2026-11-08（台北）。程式 0.13.0，架構 0.4；Linux 內含整包子檢核已驗，Windows payload 僅靜態組裝。

基本包應在無 PATH／模型環境變數時離線使用四語，不應要求使用者手動掛載。新增同平台 payload 與 build profile schema 2，固定模型、入口、原文與 SHA-256；執行時由內含資產解析目前路徑，首次完成不把安裝位置寫成絕對偏好。明確自備引擎／模型及選語仍保留，必要內含檔不符時停止 OCR，不自動換後端，文字功能仍可用。

內含模型為只讀資產，使用者模型服務不下載／移除它們；選配沿用受管專用目錄。原生入口交由 PyInstaller BINARY analysis 收集同平台相依及實際來源原文。core、full 真實四語自檢與產品發行三者分開；schema 1 缺 OCR 拒絕及無 profile 的舊來源行為保留。

Linux 開發包使用複製的 5.5.0 引擎；Windows 5.5.3 固定候選不在 Linux 執行。C03 3/4、C04 2/4、C09 3/4，完整導入仍 7/12，Windows／GPU 及最終發行門檻保留。[內含基本包契約](../bundled-base.md)。
