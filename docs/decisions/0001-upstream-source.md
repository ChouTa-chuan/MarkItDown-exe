# 0001：保留上游原始碼，透過本機轉接器接入

日期：2026-11-04。

採用 Microsoft MarkItDown 官方提交 7482c092d9c0074a89803c9fdb63a969e7fe17fc，套件版本 0.1.9，MIT 授權。將套件的 src、README、pyproject 與根授權保存於 vendor/markitdown，SHA-256 manifest 記錄未修改基線，不建立巢狀 Git checkout。

目前先不修改上游解析邏輯；本機轉接器以 convert_local 限定本機檔案，停用外掛、不配置雲端或 LLM。後續精準分析、模型及資源調度在獨立模組實作，再依樣本證據修改上游轉換器。這符合以原始碼為基礎改寫的方向，並保留可比較的更新基線。

Office/PDF 引擎目前會在原生函式執行期間持有整份文件；checkpoint 只能在前後暫停，不能宣稱逐頁回壓已完成。高壓時父程序停止派送與發出協作暫停，無法保證原生函式即刻釋放記憶體。精準流程須再拆逐頁處理。

先前普通沙箱命令無法連接 proxy:8080；核准的較寬鬆執行隔離下，原有 HTTPS 代理可成功讀取 GitHub。不能再以普通命令失敗直接判定平台代理故障；沒有停用 TLS、替換代理或繞過目的地允許規則。
