# 決策 0004：原生候選檔與可封裝來源分開驗證

日期：2026-11-08（台北）。程式 0.11.0，架構 0.4；靜態檢查機制已實作，來源再散布驗收待補。

Windows 基本包需要 Tesseract 與 DLL；官方可下載及 SHA-256 一致只能建立來源完整性，無法單獨證明每個 DLL 的來源、授權義務及 Windows 可用性。

因此新增固定候選契約、有界 PE import 解析、入口閉包及逐檔授權缺口報告。檢查不執行候選程式，不使用 PATH 補依賴；待審契約一律阻擋封裝，修改報告旗標也不能核准。既有基本 spec／full 自檢不加入此候選檔，仍回報缺原生 OCR。

實際 5.5.3 候選來源的 56 個 PE 已檢查，入口閉包 34 個，其中 32 DLL 的逐檔證據未齊。C03 固定來源／授權子檢核維持未完成；完成機制不提高完整里程碑進度。未來補齊原文／確切建置來源，或建立最小原生 build，經審查後以新契約接續 Windows 實驗證。[契約、命令與證據](../windows-native-intake.md)。
