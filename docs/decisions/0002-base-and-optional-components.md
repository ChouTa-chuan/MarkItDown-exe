# 0002：採用基本安裝包與選配元件管理

日期：2026-11-05。狀態：使用者已確認採用；功能實作另依架構指引驗收。

基本安裝包內含 Python、必要 MarkItDown／Qt 相依與可離線使用的 CPU Tesseract 繁中／英文 OCR。使用者不用自行安裝 Python、pip 或 MCP。首次啟動與選配元件管理放在既有桌面程式內，不新增帳號或常駐下載服務。

額外語言、ONNX OCR、GPU 及進階分析按需提供。元件必須具備受信任來源、固定版本、相容性、大小／資源／授權資訊、完整性驗證與健康檢查，通過後才 ready。下載／交易安裝／修復／更新／移除採獨立服務；開始安裝某元件後不用逐檔詢問，缺功能時也不默默下載大型元件。

現有 Magika 依賴 CPU ONNX Runtime，因此選配 OCR 與必要 runtime 不能只按名稱一併移除。選配 CPU／GPU 工作程序各自打包相依環境，避免主程式 runtime 被替換或 CPU／GPU 套件混裝。Windows Tesseract native、基本／選配鎖定檔、安裝與自我檢查必須同步改造。

既有轉換、RAM 回壓、桌面、品質與打包來源沿用，先透過 adapter 逐步遷移。保留 schema v5 及舊路徑，v6 遷移不更改使用者明確 OCR 選擇、不接管或移除外部資料。

實作以 [架構指引 v0.4](../architecture-guide.md) 為準。既有 19/25 是歷史基線；新增 C01–C12 導入檢核目前 0/12，兩者分開顯示。既有 ONNX 繁體品質、Windows／GPU 未驗證等限制保留；撰寫本決策不等於新元件功能完成。
