# 0003：基本 OCR 語言擴充為繁中、英文、日文、韓文

日期：2026-11-08（台北）。狀態：依使用者新增需求採用，補充既有基本包／選配規劃；架構模組仍為 v0.4。

基本包目標由繁中／英文改為四語 Tesseract。先完成固定同一官方提交的模型、明確語言選擇、設定遷移及本機實測，再整合 Windows 原生引擎。語言資料與 Windows 執行檔／DLL 分開追蹤，模型與本機推論通過不關閉 Windows 整包門檻。

以獨立四語清單及新的受管目錄維護，不改寫舊三檔清單、收據或使用者外部資料。設定 v7 讀取／備份 v1–v6，舊預設及其他偏好沿用。四語可混合解碼，但不冒充自動語言分類；缺所選模型應失敗，不靜默換語言或引擎。

日韓先採 Tesseract，ONNX／GPU 的日韓能力與品質須另有證據。四語模型約 10.6 MB，沒有把磁碟容量當成 RAM 上限。當前 C03 只完成本機子檢核，Windows 原生整合及 C03／C04／C09 全項仍待驗收。
