# PDF 精準流程

精準模式逐頁依原生文字、影像覆蓋及解碼異常，自動選擇原生解析、OCR 或空白頁。純原生短標題不強制 OCR，混合內容有提醒；快速模式仍走 MarkItDown 基線。

原生頁支援有框線／合併表格，以及對齊數值型無框線表格（含明確表頭下的稀疏缺格），僅排除已輸出的字元。雙欄以中央留白分區按左再右排序，保留跨欄標題與頁尾；最多 64 個跨欄區，超量保留原順序並提醒。相鄰表格可提示續表，仍保留各頁與重複表頭，不自動合併。學習式版面模型及任意多欄表格混排尚未完成。

OCR 使用本機 Tesseract，優先 chi_tra+eng，缺少繁中模型時提醒。PDFium 渲染上限 1,200 萬像素，使用灰階與字高正規化。文字不足最多以 200／300 DPI 嘗試兩輪，實際 DPI 受像素上限限制；每輪 90 秒逾時，OpenMP 限一執行緒。

每頁保留頁碼、路由及提醒。缺少引擎時明確失敗；OCR 無結果保留可見提醒，不視為辨識成功。取消停止 OCR 子程序並清理本次暫存。

## 模型

先從可信來源安裝 Tesseract 5，再執行：

```bash
python scripts/fetch_ocr_models.py /path/to/tessdata
```

下載約 6.4 MB 官方固定版本繁中／英文模型與 Apache-2.0 授權，使用 HTTPS 與固定 SHA-256 驗證；既有錯誤檔不靜默覆寫。桌面「模型管理」也可下載、驗證、取消及移除，並顯示來源、版本、授權與目錄。移除只處理未修改的受管理檔，保留其他檔案。

可在桌面指定 Tesseract 引擎與模型目錄後儲存，不需設定環境變數。下載成功會填入模型目錄；設定 schema v5 可讀取 v1／v2／v3／v4，在下次明確儲存時升級。CLI 載入相同設定檔也可使用。開發用途仍可設定 TESSDATA_PREFIX。

下載使用背景執行緒，支援取消，每次網路等待上限約 10 秒；已完成的有效模型可重用，中斷的暫存會清理。模型清單隨 Python 套件及 PyInstaller 包保存於 desktop_app/data，啟動不自動下載。Windows 包仍尚未包含 OCR 原生元件。

## 驗證範圍

以程式產生的英／繁中掃描、混合 PDF、表格與雙欄，檢查路由、內容、無重複、提醒、有界重試及取消。掃描案例與原生 MarkItDown 比較，只證明該樣本增加辨識內容，不代表整體準確率。

另以四份固定提交的上游公開 PDF，檢查逐格結構、頁面與金額順序、字元遺漏／重複，詳見 [版面與表格驗收矩陣](layout-acceptance.md)。公開測試樣本不等於使用者真實資料集。

測試發現過大字形會漏行或誤判，因而加入字高正規化；仍需真實低品質、旋轉、混排與多種字級評測。自動旋轉、任意區域 OCR、深度版面模型、圖片擷取及 GPU 未完成。

逐頁提供 checkpoint，但原生單頁函式及正在執行的 OCR 不能因 permit 清除立即釋放記憶體；RAM 仍是軟性預算。
