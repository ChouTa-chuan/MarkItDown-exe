# 跨頁表格候選關聯

目前提供保守的「可能延續」標記，不會直接合併表格、刪除重複表頭或補齊資料。相同表頭與幾何不能證明兩表一定相同，所有來源仍保留。

## 判斷條件

- 前後表格位於相鄰頁；前表到達頁尾 10% 範圍，後表起於頁首 12% 範圍。
- 一般無合併的表格，至少兩欄、兩列；首列各欄非空，包含文字而非純數值。
- 表頭僅正規化連續空白後完全相符，不做大小寫或繁簡轉換。
- 欄位相對頁寬位置差距不超過 0.5%；不只比欄數。
- 邊界間無其他章節／說明文字。只有完整符合頁碼格式的行可忽略，頁碼本身仍保留在輸出。
- 頁首或頁尾有多個候選表格時不關聯，避免誤接左右並排的表。

空白／OCR／無表格頁會重設候選。合併表頭、幾何不明或沒有完整首列者目前不判斷，不擅自猜測。

## 輸出

每表包含來源 ID，例如 p1-t1。候選續表會加入 possible-table-continuation 註記及可見品質提醒，指出前頁。來源頁碼、各頁表格、重複表頭、資料列、頁碼與正文全部保留。尚未輸出單一合併表，也不跨頁累積整份表格內容於記憶體；僅保留前頁的必要 metadata。

## 驗證

規則及實際 PDF 正／反例涵蓋匹配續表、不同表頭、不同欄位寬、插入新章節、空白中間頁與同頁多表。核對資料列只出現一次、重複表頭保留兩次，以及頁碼／表格 ID。

這些是程式生成樣本，不代表真實資料已完成驗收。無框線、跨頁合併儲存格、掃描續表、重複表頭缺失及自動合併仍待完成。此階段只增加可追蹤性與人工核對線索，不宣稱已完整支援跨頁表格。
